One word for the whole internet: **echochamber**.

The internet today is a million rooms where everyone hears their own
opinion bounced back at them, louder each time. This entry says it in a
single word — funny, true, and short enough to land in one beat.

## Entry

`main.py` writes exactly `echochamber` (11 characters, no trailing
newline) to `/output/entry.txt`. Deterministic, no network, no secrets.
